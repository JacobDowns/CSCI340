# Course data

Keep small, redistributable teaching datasets or generation scripts here. Do not commit restricted, personally identifiable, credential-bearing, or license-incompatible data.

For each dataset, record:

- source and stable landing-page URL;
- license and attribution requirement;
- retrieval date and version;
- transformations performed;
- field definitions and units;
- coordinate reference system for spatial data;
- missing-value conventions; and
- whether a generated or reduced student edition differs from the source.
